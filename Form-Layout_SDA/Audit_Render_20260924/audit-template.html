ข้อสังเกตจากการอ่าน SQL

  • ฐานนี้มีเอกสารจริงน้อยมาก: มีแค่ ORDR 7, OQUT 16, OPRQ 2, OJDT 2 และ Draft (ODRF) — OINV, ORCT, OVPM, OPCH, ODLN ฯลฯ ยังเป็น 0 แถว ฟอร์มส่วนใหญ่จึงได้แค่ smoke run (DocKey = -1) ที่ยืนยันว่า SQL รันผ่าน แต่ยังไม่เห็นหน้าตาข้อมูลจริง
  • UDT ของ add-on ภาษี (@SLDT_WTS_TST, @SLDT_TS_TST, @SLDT_RT_TST) ว่างทั้งหมด — PP30 / Tax Report ยังทดสอบกับข้อมูลจริงไม่ได้
  • PP30 (Command_1): เดือนมีนาคมเขียนเป็น Right(U_SubmitDate,2) = '53' แทน '03' — เดือน 3 จะไม่มีชื่อเดือน
  • Datasource ใน .rpt: ฟอร์ม 72 ไฟล์ชี้ 192.168.0.216 / SBO_SDA_REAL; รายงานภาษีชี้ SBO_SDA_Training และ Attachment of P.N.D.3 ชี้ 10.10.10.45 / SBO_NCC2 (ตอน render ตั้ง logon ใหม่ใน memory เท่านั้น)
  • GRPO (1.Goods Reciept PO) มี table ที่กรอง ORDN.DocEntry และ AR Credit Memo มี table ที่กรอง ODLN.DocEntry — น่าจะคัดลอกมาจากฟอร์มอื่น ควรตรวจเมื่อมีเอกสารจริง
  • ใบสั่งซื้อ (PO) ทดสอบด้วย Draft (ObjectId 112, ODRF DocEntry 2) เพราะยังไม่มี OPOR จริง
  • Issue for Production: formula Object_Visibility อ้าง {Approve.ApproverPicture} ซึ่งไม่มีใน Command Approve แล้ว — export พังทุกครั้ง
